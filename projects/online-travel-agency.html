Case Study

Online Travel Agency (OTA) Solution

Enterprise-level B2B & B2C travel platform with real-time flight, hotel, and package booking, serving 20+ travel partners.

April 2024 – Present Prime Tech Solutions Ltd.

Project Overview

A comprehensive Online Travel Agency platform designed to manage real-time flight, hotel, and tour package bookings for both B2B agents and B2C customers across 20+ travel partners. The system integrates external airline APIs and GDS services to keep fares, availability, and bookings synchronized in real time.

My Role & Responsibilities

  • Developed and maintained high-performance ASP.NET Web APIs and MVC applications.
  • Integrated GDS and Airline APIs for real-time fares, availability, and booking data.
  • Implemented full booking lifecycle workflows — search, book, issue, reissue, cancel, and refund.
  • Designed optimized SQL stored procedures for high-volume transactional systems.
  • Improved system reliability and performance through debugging and query optimization.

Key Features

  • Real-time flight, hotel & package search and booking
  • Support for both B2B agent and B2C customer operations
  • Full booking lifecycle management end-to-end
  • Live GDS & Airline API data integration
  • Modular, maintainable backend services

Technology Stack

ASP.NET Core ASP.NET MVC Microsoft SQL Server REST APIs GDS Integration
