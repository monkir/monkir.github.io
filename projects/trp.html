Case Study

Television Rating Point (TRP) System

Nationwide TV viewership analytics platform processing ad and program logs at scale.

Oct 2023 – Mar 2024 Dr. Anwarul Abedin Institute of Innovation

Project Overview

A system built to collect and analyze nationwide TV viewership data, generating reporting modules for ad logs, program logs, and viewer analytics to support broadcast measurement research.

My Role & Responsibilities

  • Contributed to the development of the TRP analytics system.
  • Built backend services using ASP.NET Core and MySQL for large-scale log processing.
  • Developed reporting modules generating analytical insights from ad and program logs.
  • Optimized complex SQL queries to improve reporting performance.

Key Features

  • Nationwide TV viewership data collection & analysis
  • Ad log & program log reporting modules
  • Viewer analytics insights
  • Optimized large-scale data queries for fast reporting

Technology Stack

ASP.NET Core MySQL Data Analytics Reporting
