Case Study

Hotel Central Reservation System (Hotel CRS)

Centralized reservation system for room inventory, dynamic pricing, and real-time availability across properties.

April 2025 – Dec 2025 Prime Tech Solutions Ltd.

Project Overview

A centralized Hotel Reservation System managing room categories, availability, occupancy, and inventory across properties. Cancellation policies, allotment plans, meal plans, rate plans, and discounts are configurable to support dynamic pricing strategies for hotel operators.

My Role & Responsibilities

  • Built a centralized Hotel Reservation System managing room categories, availability, occupancy, and inventory.
  • Configured Room Cancellation Policies, Allotment Plans, Meal Plans, Rate Plans, and Discounts for dynamic pricing.
  • Developed scalable Web APIs for reservation processing, availability checks, and real-time updates.
  • Created MVC-based admin panels for hotel staff to manage bookings, pricing, and policies efficiently.
  • Integrated jQuery for dynamic UI interactions and improved responsiveness across the system.

Key Features

  • Room category, occupancy & inventory management
  • Configurable cancellation policies, allotment & rate plans
  • Dynamic pricing with meal plans & discounts
  • Real-time availability checks via scalable Web APIs
  • Admin panel for staff booking & pricing management

Technology Stack

ASP.NET MVC ASP.NET Web API Microsoft SQL Server jQuery Bootstrap
