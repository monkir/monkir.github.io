Shoppinix – E-commerce Platform

Full-stack e-commerce platform with guest checkout and a mobile-first responsive UI.

May 2025 – Dec 2025 Personal Project

Project Overview

A full-stack e-commerce platform with product listings, a cart system, and guest checkout, built with a modern, mobile-first UI on top of Next.js, NestJS, PostgreSQL, and Prisma.

What I Built

  • Developed a full-stack e-commerce platform using Next.js, NestJS, PostgreSQL, and Prisma.
  • Implemented product listing, cart system, and guest checkout functionality.
  • Secured APIs with JWT authentication.
  • Built a responsive UI using shadcn/ui with mobile-first design.

Key Features

  • Product catalog & listings
  • Cart system with guest checkout
  • JWT-secured APIs
  • Mobile-first, responsive UI (shadcn/ui)

Technology Stack

Next.js NestJS PostgreSQL Prisma shadcn/ui JWT
